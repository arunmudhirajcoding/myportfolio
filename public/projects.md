# Arun Kumar Projects

## AK Meet

### Description

AK Meet is a real-time video conferencing platform inspired by modern meeting applications like Zoom.

### Problem

Remote communication requires reliable video conferencing, real-time messaging, and meeting management.

### Solution

Built a video conferencing platform using WebRTC and Socket.io to enable secure real-time video meetings and communication.

### Target Users

* Remote teams
* Students
* Individuals needing online communication

### Key Features

* Real-time video calls using WebRTC
* Live chat and signaling using Socket.io
* User authentication
* Meeting history tracking

### Technologies Used

* React
* Node.js
* Express.js
* MongoDB
* Socket.io
* WebRTC
* Material UI

### GitHub

https://github.com/arunmudhirajcoding/AK-Meet

### Live Demo

https://ak-meet.vercel.app/

## AK Resorts

### Description

AK Resorts is a full-stack resort booking platform that helps users discover, review, and book resorts.

### Problem

Travelers need a reliable platform to search, review, and book resorts, while owners need secure tools to manage listings.

### Solution

Built a resort booking system with reviews, maps, authentication, image uploads, and listing management.

### Target Users

* Travelers
* Resort owners

### Key Features

* Resort search functionality
* Maps integration
* Reviews and ratings
* User authentication
* Image uploads
* Listing management

### Technologies Used

* Node.js
* Express.js
* MongoDB
* Mongoose
* Passport.js
* Cloudinary
* Mapbox
* EJS
* Bootstrap

## Tekytalk

### Description

Tekytalk is an AI-powered voice-based learning platform that allows users to create personalized AI tutors.

### Problem

Traditional online learning lacks personalization, conversational engagement, and real-time interaction.

### Solution

Users can build custom AI tutors and learn through voice conversations powered by modern voice AI technology.

### Target Users

* Students
* Self-learners
* Professionals

### Key Features

* Custom AI tutor creation
* Real-time voice conversations
* Authentication and user management
* Subscription management

* Clerk
